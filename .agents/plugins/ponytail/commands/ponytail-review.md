---
description: Review current git diff or staged code against the Ponytail YAGNI Decision Ladder to catch over-engineering.
---
Review all modified and staged files in the current repository. Apply the Ponytail 7-rung Decision Ladder:
1. Verify if each change is strictly necessary for current requirements.
2. Flag any premature abstractions, speculative generic types, or redundant helpers.
3. Recommend simpler, direct standard library or inline implementations.
