# Graphify Knowledge Graph Query

Use this skill to query relationship paths and connections in the indexed knowledge graph.

## Procedures

- Run query command: `graphify query "<concept or symbol>"`
- Query shortest path: `graphify path "<source_symbol>" "<target_symbol>"`
- Inspect graph summary: Read `graphify-out/GRAPH_REPORT.md`
